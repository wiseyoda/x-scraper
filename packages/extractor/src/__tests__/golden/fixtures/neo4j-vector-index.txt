Neo4j 5.13 added native HNSW vector indexes. The index is created with CREATE VECTOR INDEX foo FOR (n:Label) ON (n.embedding) OPTIONS {indexConfig: {`vector.dimensions`: 1536, `vector.similarity_function`: 'cosine'}}. Once created, you can query with db.index.vector.queryNodes('foo', 10, $query). The community edition supports this without the GDS plugin.
